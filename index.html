체꼼마 개인정보처리방침

시행일: 2026년 9월 3일

개발자가 운영하는 서버는 존재하지 않으며, 개발자가 수신하거나 보관하는 개인정보는 없습니다. 광고 SDK와 개발자가 운영하는 행동분석·Crash Reporting 서비스는 사용하지 않습니다. 다만 QR 인식용 Google ML Kit가 진단·사용분석용 기술정보를 Google에 전송할 수 있으며 4항에 적었습니다.

다만 주소 검색·지도 표시·선택형 TMAP 경로 비교 기능을 사용할 때는 그 기능에 필요한 주소 또는 좌표가 카카오 또는 티맵모빌리티의 서비스로 전송됩니다. 이는 개발자에게 전송되는 것이 아니며, 전송되는 항목은 4항에 모두 적었습니다.

1. 총칙

체꼼마(이하 "이 앱")는 현장 방문 업무를 수행하는 담당자가 현장 방문 동선과 사진을 관리하기 위해 사용하는 도구입니다. 이영능(이하 "개발자")이 개인 자격으로 제작·배포합니다.

2. 이 앱이 다루는 정보

이 앱은 계정 생성이나 로그인을 위한 이름·이메일 등 이용자 식별정보를 요구하지 않습니다. 다만 기능 사용 시 이용자의 현재 위치, 카메라 및 사진에 포함된 위치정보에 접근할 수 있습니다.

이 앱이 화면에 표시하는 방문 대상자 정보(성명 또는 상호, 주소, 관리번호 등)는 이용자가 소속 기관에서 발급받은 인쇄물의 QR 코드를 직접 촬영하여 읽어들일 때 이용자의 기기로 들어옵니다. 이 정보는 해당 기기 안에만 저장되며 개발자에게 전송되지 않습니다.

증거사진은 이용자가 사진첩에서 바로 확인하고 전달할 수 있도록 공용 사진 폴더에 저장됩니다. 따라서 사진 접근 권한을 가진 다른 앱이 해당 사진과 파일명·메타데이터를 읽을 수 있습니다. 이용자는 업무가 끝난 뒤 사진첩에서 직접 삭제할 수 있습니다.

증거사진의 파일명에는 대상자의 성명이나 주소를 쓰지 않고, 소속 기관이 발급한 관리번호만 남깁니다.

4. 제3자 서비스로 전송되는 정보

이 앱은 아래의 경우에 한해 외부 서비스와 통신합니다. 외부 API와의 네트워크 통신은 HTTPS로 암호화됩니다. 아래 (4)의 길안내 앱 실행은 네트워크 통신이 아니라 기기 안에서 다른 앱을 여는 동작입니다.

(1) 카카오 (주식회사 카카오) — 주소 검색 및 지도 표시

  • 전송 항목: 검색어로 입력된 주소 또는 장소명 문자열, 좌표
  • 전송 시점: 좌표 정보가 없는 주소를 직접 입력하거나, 앱에 내장된 주소자료에서 찾지 못한 경우. 앱 내 지도 화면을 여는 경우
  • 목적: 주소를 좌표로 변환하거나 지도를 표시하기 위함
  • 이 앱은 내장된 오프라인 주소자료를 먼저 사용하며, 거기에서 찾은 경우에는 카카오로 아무것도 전송하지 않습니다

(2) 티맵모빌리티 주식회사 (TMAP API) — 같은 방문 순서의 도로 경로 비교

  • 전송 항목: 출발지·방문 지점·도착지의 경로 접근점 좌표와, 해당 요청에서만 쓰이는 임시 순번
  • 전송 시점: 앱이 오프라인 경로를 먼저 계산한 뒤, 이용자가 설명을 읽고 「동의하고 비교」를 누른 경우에만 1회
  • 목적: 앱이 정한 방문 순서를 바꾸지 않고 오프라인 도로 경로와 TMAP 도로 경로의 거리·시간을 비교하기 위함
  • 대상자의 성명·주소·관리번호는 전송하지 않습니다. 각 지점은 P01, P02와 같은 일회용 번호로만 표시됩니다
  • 비교 결과는 장기 기록으로 저장하지 않습니다. 이용자가 TMAP 안을 실제 운행 경로로 선택한 때에만 앱 재시작 복구를 위해 TMAP 도로선을 앱 전용 저장소에 최대 23시간 보관하고, 만료되면 해당 도로선을 지우고 오프라인 경로로 자동 복귀합니다

(3) Google ML Kit Barcode Scanning — QR 인식

  • 전송 항목: 기기·앱 정보, 설치별 식별자, 성능 측정치, API 구성, 기능 사용 event, 오류 코드
  • 전송 시점: 카메라나 PDF에서 QR을 인식할 때 SDK가 진단·사용분석을 위해 자동 수집할 수 있음
  • 전송 방법·목적: HTTPS, 진단·사용분석
  • Google 공식 설명에 따라 QR 본문은 수집 항목으로 공개되지 않았으며, 이 앱은 QR을 기기에서 인식하고 auto zoom을 사용하지 않음
  • 공식 정보: ML Kit Android Data Disclosure, Google 개인정보처리방침

Google의 공식 설명에 따르면 전송 중 암호화되며 제3자에게 공유하지 않습니다.

(4) 길안내 앱 실행 시

이용자가 길안내를 시작하면 기기에 설치된 TMAP·카카오맵·네이버지도 중 이용자가 선택한 앱이 실행되며, 해당 앱에 목적지의 좌표와 「목적지 3」과 같은 순번 표시가 전달됩니다. 대상자의 주소나 성명은 전달되지 않습니다. 전달 이후의 정보 처리는 각 길안내 앱의 개인정보처리방침을 따릅니다.

5. 이용자가 직접 실행하는 공유

아래 공유는 앱이 자동으로 보내는 것이 아니라 이용자가 공유 버튼이나 Android 공유 메뉴를 직접 눌러 수신 앱 또는 상대방을 선택할 때만 실행됩니다. 개발자 서버를 거치지 않으며, 전달 뒤의 처리는 이용자가 선택한 앱 또는 상대방의 정책을 따릅니다.

6. 보유 기간과 파기

개발자가 보관하는 정보가 없으므로 개발자 측의 보유 기간은 존재하지 않습니다.

기기에 저장된 정보는 다음 방법으로 삭제할 수 있습니다.

  • 앱 전용 저장소의 정보(방문 경로, 설정): 앱을 삭제하면 함께 삭제됩니다. 진행 중인 경로를 종료하여 경로만 개별적으로 지울 수도 있으며, 목적지 편집 목록은 별도의 「목적지 목록 취소」로 지울 수 있습니다
  • 선택한 TMAP 비교 도로선: 선택 시점부터 최대 23시간 뒤 자동 삭제되고 오프라인 경로로 복귀합니다. 경로를 종료하면 그 전에도 함께 삭제됩니다
  • 증거사진: 기기의 사진첩에서 직접 삭제합니다. 앱을 삭제해도 사진첩의 사진은 남습니다
